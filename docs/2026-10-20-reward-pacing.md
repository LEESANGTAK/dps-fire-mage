# 보상 연출 호흡 (2026-10-20)

## 문제
첫 몬스터 처치 0.6초 만에 각성 카드 창이 떠서, 골드 흡수·'마도서 각성 시스템 개방' 안내(3.2초)를 읽기도 전에 창이 덮었습니다.
카드 창도 한 번에 열리고, 고르는 즉시 닫히며 '각성 획득'과 '다음 도전 자동 진입' 문구가 동시에 겹쳤습니다.

## 타임라인
| 구간 | 시점 | 내용 |
| --- | --- | --- |
| 처치 | 0s | 히트스탑·사망 잔상·골드 비행. 시전 중 주문은 거두고 전투·스피드런 시계 정지(모달 정지 아님) |
| 돌파 도장 | 0.14s | `STAGE 1-1 돌파!` / 보스는 `👑 보스 격파!` 크게·길게 |
| 카드 창 | 일반 1.2s · 보스 1.9s | 머리글 → 카드 한 장씩(0.32s + 0.14s 간격, 뒤집혀 착지) → 하단 |
| 입력 잠금 | 창 열린 뒤 0.9s(리롤 0.45s) | 전투 중 연타의 잔여 클릭이 카드를 고르지 않도록 |
| 선택 여운 | 0.65s · 전설 0.95s | 고른 카드는 눌렸다 떠오르며 빛나고 나머지는 가라앉음, 전설은 화면 흔들림·불씨 |
| 진입 호흡 | 창 닫힌 뒤 0.5s | 각성 획득 문구 → 0.5s 뒤 진입 문구, 그다음 전투 재개 |
| 최종 보스 | 2.0s | 정지 대신 전투만 멈춰 소각 잔상이 끝까지 타오른 뒤 결과창 |

- 첫 처치의 '마도서 각성 시스템 개방' 토스트는 제거했습니다. 곧바로 열리는 카드 창이 같은 내용을 직접 보여 주므로 중복 안내였고,
  이를 위한 `unfolded.awakening` 세이브 플래그도 함께 지웠습니다(구형 세이브의 값은 불러올 때 무시).
- 여운 시간은 스피드런 기록에 들어가지 않습니다(`isCombatHeld()` 동안 `playTimeSec` 정지).
- 카드 효과는 고르는 순간 적용되고, 보이는 공개 연출(주문 슬롯 팝·획득 문구·메테오 연계 시연)만 창이 닫힌 뒤로 미룹니다.
- 모션 감소 설정에서는 펼침·선택 애니메이션을 끄고 입력 잠금을 0.25초로 줄입니다. 읽기 시간은 그대로 둡니다.

## 밸런스 영향
`node scripts/simulate-balance.cjs --runs 20 --policy greedy --locked`: 클리어 19/20, 런 시간 중앙 12:18
(직전 기록 77/80 · 12:36). 처치 직후 0.6초가 더 이상 시계에 들어가지 않아 런 시간이 약 0.6초 × 19스테이지만큼 짧아집니다.
