# 마도서 각성 창: 페이퍼크래프트 UI (2026-10-21)

## 바꾼 이유
각성 창이 둥근 모서리·그라데이션 바탕·바깥 네온 발광·배경 흐림·유리 버튼으로 만들어져, 만화풍·페이퍼크래프트 전장 위에서 "웹 UI 같다"는 피드백을 받았습니다.
매 웨이브 보는 화면이라 UI 재작업의 첫 대상으로 정했습니다. 다음 순서는 승리·패배 결과창 → 상단 바·토스트·진척도 같은 상시 HUD입니다.

## 레퍼런스 (브라우저에서 원본 이미지를 직접 열어 확인)
- 페이퍼 마리오 천년의 문(Switch) 메뉴: [Super Mario Wiki 갤러리](https://www.mariowiki.com/Gallery:Paper_Mario:_The_Thousand-Year_Door_(Nintendo_Switch))의 `TTYDNS_Party_Menu.jpg`, `TTYDNS_Badge_List_Menu.jpg`(1280×720).
  - 무늬가 은은하게 찍힌 두꺼운 판지 위에 한 단 밝은 종이판을 겹친 구조.
  - 이름표·탭은 모서리를 깎은 종이 띠. 밝은 종이 위 짙은 글자로 읽기 쉬움.
  - 선택 칸은 크림색 종이 한 장을 올린 형태(발광 아님).
- [Erin Brume — Paper GUI](https://erinbrume.itch.io/paper-gui/devlog/826208/paper-gui-assets): 양끝이 접힌 리본 제목판, 납작한 단색, 요소마다 흰 오림 테두리.
- 영상(움직임)은 보지 않았습니다. 움직임은 게임 안 기존 종이 문법(화상 불꽃·마법진의 끊어 움직이기)을 따랐습니다.

## 재해석 규칙 (`styles.css` 7-1 ~ 7-5)
- 금지: 둥근 모서리(14~18px), 그라데이션 바탕, 바깥 발광 그림자, 배경 흐림, 알약 배지.
- 사용: 짙은 잉크 테두리(`#241b22`) + 크림색 오림선(`#fff0c5`) + 아래로 딱 떨어지는 짧은 층 그림자(`#151119`). 색은 전투 HUD 종이(`paper-ui.css`)와 같은 판지·크라프트·크림 계열.
- 판: 잉크 테두리 → 크라프트 띠 → 잉크 선 → 점무늬 찍힌 짙은 판지(무늬는 CSS 점 패턴, 이미지 없음).
- 제목: 판 위쪽 테두리에 걸쳐 붙인 크림색 리본. 양옆 꼬리는 한 톤 어두운 종이를 V자로 오려 뒤에 끼움.
- 카드: 크림색 카드 면 + 등급 색종이 테두리(일반 크라프트 회갈 · 희귀 파랑 · 전설 금색) + 잉크 외곽선. 손으로 늘어놓은 듯 카드마다 -1.6° / 0.9° / -0.6° 기울임.
  - 등급은 위쪽 테두리에 걸친 색종이 꼬리표. 보유 수는 오른쪽 위 크라프트 꼬리표.
  - 전설: 위쪽 두 모서리의 금색 별 스티커가 종이 인형처럼 끊어 반짝임(발광 대신).
  - 빌드 분류 위는 절취선(점선).
- 글자: 밝은 종이 위 짙은 잉크, 강조 수치는 진홍(`#b3261e`). 기존 어두운 바탕의 밝은 글자보다 대비가 높습니다.
- 버튼: 두꺼운 주황 종이(잉크 테두리 3px + 아래 그림자 4px). 누르면 그림자만큼 내려앉음. 골드가 모자라면 크라프트 회색 종이. '선택 없이 넘기기'는 점선 크라프트 테두리.
- 움직임
  - 펼침: 한 장씩 뒤집혀 들어와 각자의 기울기로 착지.
  - 전설: 한 바퀴 더 돌아 탁 내려앉음(스쿼시).
  - 마우스 오버: 기울기를 펴며 떠오르고 그림자가 길어짐.
  - 선택: 고른 카드는 집어 올려지고, 나머지는 기울어지며 미끄러져 사라짐.
- 모바일(≤640px): 위에서부터 쌓아 리본이 잘리지 않게 하고, 하단은 골드 꼬리표 한 줄 + 버튼 한 줄로 접습니다.
- 모션 감소 설정: 펼침·선택·스티커 애니메이션을 끕니다.

## 함께 정리한 것
- HTML에서 이미 지운 웨이브 돌파 배지(`awakening-wave-tag`)를 갱신하던 JS와 영어 문구를 제거했습니다.
- 스타일이 없던 다시 뽑기 셔플 클래스(`cards-shuffle-pop`) 코드를 제거했습니다(다시 뽑기는 펼침 연출로 새 카드가 들어옵니다).

## 검증
- 브라우저(1280×900, 375×812)에서 일반·희귀·전설 카드 한 장씩, 마우스 오버, 골드 충분·부족 버튼을 확인했습니다. 가로 넘침 없음, 콘솔 오류 없음.
- 한계: 종이 질감은 CSS 점 패턴만 썼습니다. 그래도 밋밋하면 작은 반복 질감 이미지 하나를 추가하는 안을 검토합니다.
