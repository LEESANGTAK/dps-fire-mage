# 승리·패배 결과창: 페이퍼크래프트 UI (2026-10-21)

각성 창(`docs/art/PAPER_AWAKENING_UI.md`)과 같은 레퍼런스·규칙을 결과창에 적용했습니다. 레퍼런스는 페이퍼 마리오 천년의 문 리메이크 메뉴와 Erin Brume Paper GUI입니다.
결과창 스타일은 모두 `paper-ui.css`의 결과창 구역 한 곳으로 모았습니다. `styles.css`에 흩어져 있던 웹 스타일(그라데이션 판·네온 발광·배경 흐림·발광 맥동 키프레임)은 지웠습니다.

## 구성
- 판: 각성 창과 같은 점무늬 판지(잉크 테두리 → 크라프트 띠 → 잉크 선).
  - 등장은 종이 한 장이 펄럭이며 내려앉는 오버슈트입니다(밝기 번쩍임 없음).
- 머리 리본: `VICTORY · SPEEDRUN COMPLETE` 띠를 크림색 리본으로, 양옆에 V자 꼬리를 달았습니다.
  - 패배는 진홍 종이 리본과 진홍 판 테두리입니다.
- 스피드런 기록지: 크림색 종이 위 짙은 잉크 숫자.
  - 이번 기록은 주황, 최단 기록은 금색 띠를 위에 두른 종이 칸입니다.
  - 신기록 배너는 금색 종이, 기록 꼬리표는 종이 인형처럼 끊어 흔들립니다.
- 전투 요약 6칸·피해 점유율·숙련도·새 런 설정·패배 진단: 짙은 종이 한 장(잉크 테두리 + 크라프트 안쪽 선 + 짧은 그림자).
  - 요약 칸은 왼쪽에 크라프트 띠를 둘렀습니다.
  - 피해 점유율과 숙련도 막대는 홈 파인 종이 위에 색종이 띠가 차는 모양입니다(숙련도는 빗금 결).
  - 새 런 설정은 절취선(점선) 테두리입니다.
- 해금 칩: 크림색 꼬리표 + 왼쪽 색종이 띠(카드 금색 · 업화 진홍). 마우스를 올리면 살짝 들립니다.
  - 카드 설명 툴팁도 크림색 종이 카드로 바꿨습니다(짙은 글자, 진홍 강조).
- 업화 단계 칩·시작 주문서 칩: 네모난 종이 말입니다. 고른 것은 주황 종이로 칠해지고 눌린 듯 내려앉습니다.
- 버튼
  - 다시 도전: 두꺼운 주황 종이 버튼. 누르면 내려앉고, 1.6초마다 살짝 들썩여 다음 런을 권합니다(발광 맥동 대신).
  - 닫기: 크림색 종이 단추.
- 모바일(≤640px): 요약 칸을 한 줄씩 쌓습니다. 가로 넘침 없음(375px 확인).
- 모션 감소 설정: 등장·꼬리표 흔들림·버튼 들썩임·해금 팝을 끕니다.

## 검증
- 브라우저 1280×900에서 업화 1단계 첫 클리어(숙련도 레벨업 + 해금 5칸 + 업화 해금 카드)와 10스테이지 보스 광폭화 패배 화면을 위아래로 스크롤하며 확인했습니다. 375×812도 확인했습니다. 콘솔 오류 없음.
- HTML에서 스타일 없는 `speedrun-retry-btn` 클래스를 지웠습니다.
