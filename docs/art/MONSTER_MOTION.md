# 몬스터 재질별 대기·피격·사망

## 참고와 반영

- https://www.fab.com/listings/fb5b4170-2bd6-496f-bdd9-613fca6b6ad0 : 제작자 소개의 랜덤 대기·복수 피격·사망 구성을 검토했습니다.
- https://www.youtube.com/watch?v=Ks5yyim2ODE : 실제 재생 화면의 몸 전체 무게 이동과 몸을 낮추는 동작을 확인했습니다. 형태가 젤리처럼 변하는 대신 몸의 방향과 무게로 반응하도록 재해석했습니다. 영상 전체의 모든 상태를 프레임별 분석한 것은 아닙니다.
- https://realtimevfx.com/t/one-of-my-first-vfxs/3099 : 검색에 제공된 제작자 설명과 피드백에서 소멸 뒤 불꽃 생성이 계속되지 않도록 수명을 분리하는 관점을 확인했습니다. 원문 재접속은 503 오류로 실패했으며 해당 영상은 재생 확인하지 않았습니다.
- 슬라임의 기존 검토 자료와 사용자 측면 분출 스케치를 재사용했습니다. 에셋은 복제하지 않았습니다.

## 구현

현재는 22가지 종이 몬스터 모습을 사용합니다. 20개 기본 재질 프로필과 심연 영체 프로필을 유지합니다. 종이 원화 전체의 실시간 압축은 0이며 슬라임만 새로 그린 4포즈로 눌림·복원을 표현합니다. 일반·좌우·강화 타격의 반동과 시간이 다릅니다. 기본 원화·모션 연결과 참고 조사는 `PAPER_MONSTERS.md`에 기록했습니다.

| 대상 | 대기·피격 | 사망 |
|---|---|---|
| 초록·파랑 슬라임 | 종이 4포즈와 서로 다른 주기 | 종이 접힘·기존 측면 점액 비산 |
| 들쥐·멧돼지·늑대 | 체중별 작은 호흡·움찔 | 옆으로 쓰러짐 |
| 고블린·놀·오우거 | 무게별 경계 자세·젖힘 | 무게를 싣고 쓰러짐 |
| 해골 | 형태 유지·작은 흔들림 | 뼛조각 낙하 |
| 전갈·거미·도마뱀 | 갑각은 압축 없음·낮은 반동 | 뒤집혀 수축 |
| 박쥐·비룡 | 부유/무게별 자세 | 낙하하며 쓰러짐 |
| 바위 파수꾼 | 압축 없이 묵직한 진동 | 돌 조각 낙하·붕괴 |
| 기사단원 | 압축 없이 경직 | 금속 조각 낙하·붕괴 |
| 어둠마법사·밴시·파멸수호병 | 체중 또는 부유 반응 | 흐트러져 소멸 |
| 라그나로스 | 불꽃의 흐름 | 불씨를 남기며 꺼짐 |

초상화 유리 파괴 호출과 공통 파괴 사운드를 제거했습니다. 새 종이 원화를 사용하는 CSS 정지 자세·변형·잔상·기존 Canvas 파티클 방식입니다. 슬라임은 4포즈이며 나머지는 단일 원화입니다. 독립 관절 애니메이션은 아닙니다. 즉시 재생성하는 전투 흐름은 유지하고 이전 몬스터의 잔상으로 사망 여운을 표현합니다. 사망 잔상은 최대 3개, 추가 사망 파티클은 최대 48개입니다. 모션 감소 설정은 짧은 페이드만 남깁니다.

## 검증

비교 화면에서 20종 모두 강화 피격 진폭·사망 CSS 분기를 실제 확인했습니다. 바위·뼈·갑옷·갑각의 압축 0과 다른 생물의 상한, 서로 다른 사망 종류를 회귀 검증했습니다. 이 문서의 기존 비교 검증은 만화 원화 시점 기록입니다. 현재 종이 원화의 비교·실제 게임 검증은 `PAPER_MONSTERS.md`에 따로 기록했습니다. 종이 슬라임은 paper-puddle 사망 분기를 사용합니다. 장시간 고속 연사 성능 측정과 모든 후반 스테이지의 실제 전투는 확인하지 않았습니다.
