# 불장판: 오려 붙인 종이 불꽃 (2026-10-20)

## 바꾼 이유
기존 불장판은 사진에 가까운 질감의 PNG(`comic-flame-patch.png`, 용암 균열 돌바닥 + 그라데이션 불길)를 화면(screen) 합성·블러로 깔았습니다.
만화풍·페이퍼크래프트 전장 위에서 "사진을 오려 붙인 것 같다"는 피드백을 받아, 전투 중 바닥 효과는 원화를 쓰지 않고 캔버스에 직접 그립니다.
(액션바·카드 아이콘은 기존 아이콘을 그대로 씁니다.)

## 그림 문법 (`comic-assets.js` `drawPaperFlamePatch()`)
몬스터 화상 상태의 종이 불꽃(`art.css` `.paper-flame`, 참고: `docs/art/MONSTER_MOTION.md`의 페이퍼 마리오 천년의 문 화상 표현)과 같은 문법을 씁니다.
- 바닥: 가장자리를 손으로 오린 짙은 갈색 종이(고정 요철 16점) + 안쪽 잉걸빛 종이 타원, 크림색 오림선.
- 불꽃 8장: 뒷줄 4장(작고 높게) → 앞줄 4장 순서. 가운데는 몬스터가 서 있어 양옆을 크게 둡니다.
- 불꽃 한 장: 주황 바탕(`#f26a1b`) + 진홍 밑단(`#c8321b`) + 노란 속불(`#ffd36b`) 3겹 색종이, 크림색 오림 테두리(`#fff0c5`), 아래로 떨어지는 짧은 층 그림자.
- 움직임: 0.5초마다 3포즈(기본·세로로 늘며 왼쪽 기울기·가로로 퍼지며 오른쪽 기울기)를 끊어 바꿉니다. 불꽃마다 위상이 달라 동시에 깜빡이지 않습니다.
- 빛 번짐 없음: 블러·screen 합성·방사형 발광을 쓰지 않고 호출자의 소멸 알파만 곱합니다(마지막 0.6초 페이드는 `game.js`).
- 불티 파티클은 초당 최대 6회 생성 확률로 줄였습니다(전체 180개 상한 유지).
- 모션 감소 설정: 호흡 크기 변화와 포즈 전환, 추가 불티를 끕니다.

- 한계: 새 웹 레퍼런스를 추가로 찾지 않고, 이미 검증한 화상 종이 불꽃의 레퍼런스와 형태를 재사용했습니다.
