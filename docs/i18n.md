# 다국어(한국어·영어)

## 구조
- `src/scripts/i18n.js`: 언어 선택과 번역 함수 `tr()`. **한국어 원문을 그대로 키로** 씁니다.
  - 코드: `tr('👑 보스 격파!')`, 수치는 자리표시자 `tr('{n}초', { n: 3 })`.
  - 정적 HTML: 시작 시 텍스트 노드·`title`·`aria-label`을 원문 일치로 바꿉니다. 인라인 태그가 섞인 문장은 요소에 `data-i18n-html`을 달면 innerHTML 전체가 하나의 키가 됩니다.
  - 큰 수: 한국어 만·억, 영어 K·M (`I18N.formatNumber`, 게임의 `fmt()`가 사용).
- `src/scripts/i18n-en.js`: 영어 사전(원문 → 영어).
- 카드: 엑셀 `영문 이름(title_en)`·`영문 설명(desc_en)` 열 → `roguelike-cards.json` → `cardText(card, 'title')`. 비워 두면 한글로 대체 표시.

## 언어 결정
저장된 선택(`DPS_FIRE_MAGE_LANG`) → 브라우저/OS 언어(ko로 시작하면 한국어, 그 외 영어). 상단 🌐 버튼으로 바꾸면 저장 후 새로고침합니다. Steam 빌드는 OS 언어를 따릅니다(Steam 클라이언트 언어 연동은 Steamworks SDK 작업 때 추가).

## 문구를 추가·수정할 때
1. 코드에서 화면 문구를 `tr('원문')`으로 감쌉니다(동적 수치는 `{이름}`).
2. `node scripts/i18n-keys.cjs` → 영어 사전에 없는 원문이 출력됩니다. `i18n-en.js`에 추가합니다.
3. `tests/i18n.test.cjs`가 누락·미사용 키, 자리표시자·태그 불일치, 영어 번역 속 한글을 막습니다.

번역하지 않는 것: 개발용 밸런스 로그 리포트(배포 빌드에서는 버튼이 없음), 콘솔 로그.
