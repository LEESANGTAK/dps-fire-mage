## 1. 한 줄 포지셔닝

> **"레이드 뛸 시간은 없어도, 딜사이클 손맛은 그리운 사람을 위한 15분 로그라이트 스피드런."**
> **"코스는 매번 같고, 빌드는 매번 다르다."**

| 축 | 우리 게임 | 비교 |
| --- | --- | --- |
| 손맛 | 화염구·불꽃 작렬·메테오·마력 폭주·불장판 5주문 딜사이클, 치명타 연쇄 프록 | MMO 화법의 핵심만 추출 |
| 빌드 | 스테이지마다 마도서 각성 카드 선택(속사·치명·정령·화상) — **런마다 바뀌는 유일한 요소** | Brotato·Vampire Survivors류 런 빌드 |
| 코스 | 20스테이지·몬스터·보스·순서 고정 | 고정 코스라 기록 비교가 공정함 |
| 압박 | 5·10·15·20 보스 광폭화 타이머 = 딜 체크(Gear Check) | 레이드 딜컷의 축소판 |
| 반복 동기 | 스피드런 기록, 업화 0~8단계, 실패해도 쌓이는 숙련도 해금 | 로그라이트 메타 진행 |
| 피로도 | 맵 이동·파티·즉사 기믹 없음, 자동 시전 토글 | 하드코어 MMO 대비 극저 |

### 우리가 **아닌** 것 (기대 불일치 방지)
- **방치형/증분(Idle·Incremental) 게임이 아닙니다.** 숫자가 런을 넘어 무한히 쌓이지 않고, 오프라인 보상도 없습니다. 이 장르 팬을 데려오면 "매 판 리셋된다"는 이유로 부정 리뷰가 나기 쉽습니다.
- **무료+과금(F2P) 게임이 아닙니다.** 광고 제거·배틀패스·영구 배율 판매는 하지 않습니다. 유료 Steam 게임에서 이런 구조는 리뷰를 깎습니다.
- **하드코어 MMO 시뮬레이터가 아닙니다.** 20개 단축키나 정밀 회피는 넣지 않습니다.
- **Slay the Spire식 로그라이크 덱빌더가 아닙니다.** 갈림길 지도·이벤트·상점·무작위 엘리트가 없습니다. 이 기대를 부르는 'Roguelike Deckbuilder' 태그와 '로그라이크' 표현은 앞세우지 않고, 고정 코스를 **기록 경쟁의 공정성**이라는 장점으로 내세웁니다.

## 2. 누구에게 (타겟)

### 2.1 1차 타겟: MMO 딜러 출신 직장인 게이머
- 20~40대, 와우·로스트아크·메이플·디아블로에서 딜미터기와 딜사이클을 경험.
- 퇴근 후 2~3시간 레이드는 부담스럽지만, 무지성 클리커는 5분 만에 질림.
- 쿨다운·GCD·시전 시간·치명타·도트·프록에 익숙함 → **설명 없이도 손맛을 바로 알아봄.**

### 2.2 2차 타겟: 짧은 로그라이트·스피드런 유저
- Brotato, Vampire Survivors, Magic Archery류(고정 웨이브 + 런 빌드)를 즐기는 Steam 유저. 매번 다른 지도를 기대하는 Slay the Spire 유저는 핵심 타겟이 아님.
- 15분 안에 끝나는 런, 매 판 다른 빌드, 기록 단축에 반응.
- 이들은 MMO 맥락을 몰라도 **"카드 고르고 → 숫자 터지고 → 보스 시간 안에 잡기"**로 이해할 수 있어야 함 → 스토어 첫 스크린샷·트레일러 첫 5초는 MMO 용어 없이 이해되도록 구성.

### 2.3 적정 매운맛
- **지양(너무 매움):** 실수 한 번에 15분이 날아가는 허무함 → 실패해도 숙련도 경험치 지급으로 완화(구현됨).
- **지양(너무 밍밍):** 자동 시전만 켜 두면 끝나는 런 → 업화 4단계 이상은 수동 연계가 기록 차이를 만들도록 유지.
- **지향:** 3~5개 주문의 프록 연쇄 + 카드 선택 판단 + 보스 딜 체크.

## 4. Steam 태그 후보

Steam은 상위 태그일수록 노출·추천에 큰 영향을 줍니다. **실제로 런마다 바뀌는 것은 빌드뿐이고 코스는 고정**이라는 사실에 맞춰, 장르 정체성 → 핵심 재미 → 분위기 순으로 배치합니다. (실제 등록 시 Steamworks 태그 목록에 있는 이름인지 확인)

### 4.1 상위 5개 (핵심, 가장 중요)
1. **Action Roguelike** — 실시간 딜사이클 손맛 + 런 빌드
2. **Roguelite** — 실패해도 쌓이는 메타 진행(숙련도·업화 단계)
3. **Speedrun** — 고정 코스 15분 기록 단축
4. **Card Battler** — 매 스테이지 카드 선택
5. **Score Attack** — 단계별 최단 기록 경쟁

### 4.2 보조 (6~15)
Short · Replay Value · Magic · Fantasy · Singleplayer · 2D · Stylized · Cartoon · Casual · Roguelike Deckbuilder(맨 뒤, 노출 보조용)

### 4.3 넣지 않거나 상위에 두지 않을 태그
| 태그 | 이유 |
| --- | --- |
| Roguelike Deckbuilder (상위) | Slay the Spire식 지도·이벤트·상점·무작위 보스 기대 → 고정 코스와 불일치. 맨 뒤 보조로만 둠 |
| Roguelike, Procedural Generation | 스테이지가 절차 생성되지 않음 |
| Idle, Clicker, Incremental | 런 단위 리셋·오프라인 보상 없음 → 기대 불일치로 부정 리뷰 위험 |
| Auto Battler | 자동 시전은 편의 기능일 뿐, 수동 손맛을 약속하는 소개문과 충돌 |
| MMORPG, RPG | 온라인·장기 육성을 기대하게 만듦 |
| Difficult, Souls-like | 적정 매운맛 지향과 반대 신호 |

### 4.4 스토어 문구 원칙
- "로그라이크" 대신 **"로그라이트"**, "매 판 달라지는 스테이지" 대신 **"같은 코스, 매 판 다른 빌드"**로 씁니다.
- 고정 코스는 숨기지 않고 **"기록은 빌드와 실력만으로 갈린다"**는 장점으로 표현합니다.
- 클리어 후 콘텐츠(업화 단계 1~8, 숙련도 해금)를 명시해 반복 동기를 약속합니다.
- 실제 문구: `docs/steam-store/store-description.md`

### 5.2 출시 전 필수 (11월 말까지)
1. **Electron 래퍼 + 파일 세이브 + Steamworks 연동** 마무리 (`docs/desktop-build.md`).
2. **BGM 교체**: Suno 무료 플랜 제작물은 상업 이용 불가 → 출시 전 교체.
3. **블리자드 IP 잔재 최종 점검**: 코드상 명칭은 제거됨. 몬스터·보스 외형과 스토어 문구를 눈으로 마지막 확인.
4. ~~**밸런스 이상치 수정**~~ ✅ 2026-10-15: 원인은 전설 카드 획득 운과 들불의 약세였음. 보스 보상 전설 보장·들불 재설계·불사조 하향으로 0단계 p75 13:12 → 10:50 (`docs/2026-10-15-legendary-balance.md`).
5. **캡슐·키아트 교체**: 현재 임시본 (`docs/steam-store/README.md`).
6. **첫 런 FTUE 플레이테스트**: MMO 경험 없는 2차 타겟 기준으로 첫 3분 이탈 여부 확인.

### 5.3 출시 후 업데이트 후보 (반복 동기 강화)
- **런 성장 체감 결과창:** 첫 스테이지 대비 최종 DPS·최대 한 방을 나란히 보여주어 "이만큼 강해졌다"를 시각화(증분 게임의 숫자 쾌감을 런 안에서 차용).
- **런 간 단축 체감:** 숙련도 해금 후 클리어 시간 단축(시뮬 기준 16:29 → 10:31)을 명예의 전당에 추세로 표시.
- **훈련용 허수아비 모드:** 30/60초 DPS 측정, 최고 기록 공유 → 커뮤니티 인증 글 유도.
- **페이즈 보스 무작위 변형:** 5·10·15 보스에 런마다 변형 하나(예: 화상 면역, 치명타 반사 보호막)를 붙여 빌드 판단을 바꿈. 기록 비교를 위해 결과창에 변형 표시. 플레이테스트에서 '반복이 지루하다'는 반응이 나오면 출시 전으로 앞당김.
- **갈림길 지도·이벤트:** Slay the Spire식 기대에 가장 잘 맞지만 아트·밸런스 비용이 커 대형 업데이트 후보로 둠.
- **신규 지역·직업(냉기/비전):** 장기 업데이트 소식으로 재노출.

## 6. 결론
우리가 파는 것은 **"짧은 시간 안에 딜사이클을 굴려 보스 딜 체크를 넘는 손맛"**입니다. 방치형 장르의 성장·과금 공식을 따르지 않고, 로그라이트·스피드런 유저와 MMO 딜러 출신 유저가 만나는 지점에 태그·채널·스토어 문구를 정확히 맞추는 것이 출시 전 마케팅의 핵심입니다.
