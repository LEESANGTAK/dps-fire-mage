# 몬스터 위계와 아이콘·마법부여 가독성 수정

## 확인한 레퍼런스와 적용

- Blizzard Warcraft Rumble 공식 설명: https://news.blizzard.com/en-us/article/24091205/earn-powerful-rewards-in-molten-core
  - 원문에서 일반 적과 최종 보스의 역할 구분을 확인했습니다.
  - 공식 원화 https://bnetcmsus-a.akamaihd.net/cms/content_folder_media/5j/5JDWVGJRPT711715753325135.png 를 직접 열어 큰 상체·넓은 어깨·세로 실루엣을 확인했습니다. 이미지 복제 없이 기존 원화의 표시 크기에만 위계를 적용했습니다. 영상·새 애니메이션은 다루지 않았습니다.
- W3C 대비 기준: https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html
  - 원문에서 일반 글자의 명도 대비 4.5:1 기준을 확인했습니다. 어두운 마법부여 카드에 밝은 제목·설명 색상을 적용했습니다.
- W3C 글자 확대 기준: https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html
  - 원문에서 확대 시 내용 잘림을 피해야 한다는 설명을 확인했습니다. 설명 글자와 줄 간격을 늘리고 기존 유연한 카드 배치를 유지했습니다. 200% 확대 실측은 미검증입니다.

## 변경

- 슬라임을 축소하고 일반 몬스터는 진행 단계에 따라 점진적으로 확대합니다. 5단계마다 보스를 추가 확대하며 무한 심연에서도 기본 접지 틀의 1.8배로 제한합니다. 모바일의 기존 접지 틀을 기준으로 비례 축소합니다.
- 접지 위치와 기존 재질별 대기·피격·사망 모션을 유지합니다. 슬라임에서 일반 몬스터로 넘어갈 때 아래쪽 위치를 초기화합니다.
- 5·6번 스킬의 이미지에 절대 위치와 전체 영역을 지정합니다. 특성 노드와 상세 아이콘에도 부모·자식 크기를 지정하여 배경 이미지 영역이 사라지는 문제를 해결합니다.
- 마법부여 카드의 제목·설명·최대 단계 배경·비활성 버튼 글자 대비를 개선합니다.
- 수정한 스타일과 이미지 설정 스크립트의 캐시 버전을 갱신합니다.

## 검증과 한계

- 기존 몬스터·마법사 모션 검사 및 이미지 선택 검사가 통과했습니다.
- 단계별 크기, 보스 증가, 무한 심연 크기 상한, 슬라임 복원과 일반 몬스터 접지 초기화를 검사했습니다.
- JavaScript 구문과 변경 파일 공백 검사를 통과했습니다.
- 로컬 파일 URL 접근이 브라우저 보안 정책에 차단되어 실제 전투 화면·고속 연사·모바일 배치의 육안 확인은 수행하지 못했습니다.
