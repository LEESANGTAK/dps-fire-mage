# 클리어 후 콘텐츠 — 업화 단계 · 마도서 숙련도 · 실패 보상

## 왜 필요한가
- 한 판이 15분 내외라 첫 클리어 후 할 일이 없으면 Steam 2시간 환불 기간 안에 환불되기 쉽습니다.
- 광폭화 실패 시 남는 것이 없어 15분을 쓴 런이 허무하게 끝났습니다.

## 구성
| 시스템 | 역할 | 데이터 |
| --- | --- | --- |
| 업화 단계(Inferno 0~8) | 클리어 후 난이도 사다리. 해금된 최고 단계로 최종 보스를 쓰러뜨리면 다음 단계 해금 | `meta-progression.js` `INFERNO_RULES` |
| 마도서 숙련도(Mastery) | **실패해도** 돌파한 만큼 쌓이는 영구 경험치. 기준을 넘을 때마다 전설 카드·시작 주문서 해금 | `MASTERY_XP`, `MASTERY_UNLOCKS` |
| 시작 주문서 | 해금한 주문서 하나를 들고 런 시작(불꽃 작렬·불장판·메테오·마력 폭주) | `START_SPELL_CARDS` |
| 단계별 기록 | 스피드런 최단 기록을 업화 단계마다 따로 저장 | 세이브 `meta.bestTimes` |

### 업화 단계 규칙(누적)
1. 몬스터 체력 +15% · 2. 10스테이지 이후 보스 광폭화 -10% · 3. 다시 뽑기 비용 +50% · 4. 보스 체력 +20% · 5. 일반 웨이브 선택지 3→2장 · 6. 10스테이지 이후 보스 광폭화 -10% 추가 · 7. 불의 심장 보호막 +50% · 8. 모든 몬스터 체력 +20% 추가

광폭화 단축을 10스테이지 이후 보스로 한정한 이유: 처음 설계(모든 보스)로 시뮬레이션하자 6단계 실패 10회 중 7회가 5스테이지 보스에서 났습니다. 런 초반 5분 만에 끝나는 벽은 허무하므로, 압박은 빌드가 갖춰진 후반 보스에 둡니다.

숫자만 키우지 않고 선택지·리롤·기믹을 섞어, 같은 덱이라도 단계마다 판단이 달라지게 했습니다.

### 숙련도
- 런 경험치 = 일반 스테이지 1 + 페이즈 보스(5·10·15) 3 + 최종 보스 10, 업화 단계마다 +25%.
  - 예: 5스테이지 보스 실패 4, 10스테이지 보스 실패 11, 0단계 클리어 35, 4단계 클리어 70.
- 해금 순서(누적 경험치): 10 화염 기관총 → 25 시작 불꽃 작렬 → 45 잿더미 군단장 → 70 시작 불장판 → 100 들불 → 140 시작 메테오 → 190 진홍의 마력 폭주 → 250 불사조의 가호 → 320 시작 마력 폭주.
- 전설 카드 5종은 첫 런에 잠겨 있습니다. 첫 런은 기본 카드로 손에 익히고, 런을 거듭할수록 강한 조합이 열립니다.
- 전체 해금 ≈ 320 경험치 ≈ 0~4단계 클리어 6~8회 + 실패 몇 회(약 2~3시간). 환불 기간(2시간)을 넘어서까지 목표가 남습니다.

## 화면 (meta-ui.js)
- 결과창(승리·실패 공통) 위쪽: 숙련도 막대가 이번 런 경험치만큼 차고, 기준을 넘으면 해금 칩이 하나씩 튀어나옵니다(0.45초 여운 → 0.9초 채움 → 0.38초 간격 공개). 다음 해금 아이콘과 남은 경험치를 항상 보여줍니다.
- 다시 도전 버튼 위: 새 런 설정. 업화 단계 불꽃 버튼(잠긴 단계 🔒)과 현재 단계 규칙, 단계별 최고 기록, 시작 주문서 아이콘. **고를 것이 생긴 뒤에만** 펼칩니다.
- 전투 화면: 스테이지 표시 옆 🔥N 배지(0단계에서는 숨김).
- 참고: 결과창은 막대 하나와 현재·다음 단계만 남기고, 해금은 하나씩 공개하며, 영구 해금임을 명시하는 결과 화면 사례를 따랐습니다.
