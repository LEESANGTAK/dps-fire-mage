## 1. 현재 진단 (코드·데이터 기준)

### 1.1 카드 풀 (28장, `src/data/roguelike-cards.json`)

| 빌드 | 일반 | 희귀 | 전설 | 카드 |
| --- | --- | --- | --- | --- |
| 속사 | 1 | 3 | 1 | 신속의 불꽃(시전속도 +20%, ×5) · 분열 화염구 · 과부하 시전 · 속사 장전 · **화염 기관총**(업화 3단계) |
| 치명 | 3 | 5 | 1 | 주문서: 불꽃 작렬 · 타오르는 집중(×5) · 작열하는 열기(×5) · 무모한 일격 · 주문서: 메테오 · 태양석 메테오 · 잠열 충전 · 주문서: 마력 폭주(업화 2단계) · **진홍의 마력 폭주**(숙련도 190) |
| 정령 | 2 | 2 | 1 | 화염 정령 소환(×4) · 정령의 분노(×5) · 일제 협공 사격 · 정령 계약 · **잿더미 군단장**(숙련도 45) |
| 화상 | 1 | 2 | 1 | 맹렬한 화상(×5) · 주문서: 불장판 · 번지는 불길 · **들불**(숙련도 10) |
| 공용 | 1 | 2 | 2 | 마력 증폭(×5) · 처형인의 불꽃 · 유리 대포 · **불사조의 가호**(숙련도 250) · **자동 영창**(숙련도 35, 피해 없음) |

※ 위 표의 일반·희귀 칸은 JSON의 `rarity` 값을 그대로 셌습니다(주문서 4장 중 불꽃 작렬만 일반, 나머지는 희귀).

### 1.2 문제

1. **추첨이 빌드를 모릅니다.** `drawChoices`(`roguelike-deck.js`)는 등급 가중치(일반 웨이브 일반 75·희귀 21·전설 4 / 보스 희귀 85·전설 15)로만 뽑습니다. 정령 카드를 3장 골라도 다음 선택지에 정령 카드가 더 나오지 않아, 계획이 운에 흩어집니다.
2. **선택의 상당 부분이 수치 겹치기입니다.** 한 런의 선택은 약 19번(1~19스테이지 클리어, 보스 보상 3번 포함)인데, 최대 5번 겹치는 수치 카드가 6장(합계 30칸)이라 갈림길보다 '숫자 큰 쪽 고르기'가 많습니다.
3. **연계는 치명 빌드에만 있습니다.** 불꽃 작렬(확정 치명) → 열기 → 메테오, 마력 폭주(전부 치명) → 진홍의 마력 폭주처럼 카드가 서로의 조건을 채우는 구조는 치명 빌드뿐입니다. 속사·정령·화상은 대부분 자기 수치만 올립니다.
4. **주문서가 특정 빌드에 묶여 있습니다.** 4장의 주문서(불꽃 작렬·메테오·마력 폭주·불장판)는 모든 빌드가 갈라지는 축인데, 3장이 '치명', 1장이 '화상'으로 분류돼 있습니다.
5. **초반 런에는 전설이 거의 없습니다.** 첫 런은 전설 전부 잠김, 숙련도 10에서 들불, 45에서 잿더미 군단장. 치명 전설은 190, 속사 전설은 업화 3단계라, "전설을 중심으로 짜는" 경험이 늦게 시작됩니다.
6. **만날 수 있는 카드를 볼 곳이 없습니다.** 도감이 없고, 새 런 설정의 해금 예고가 유일한 단서입니다.

## 2. 카드 개편

### 2.1 분류 재편: 주문서 + 6빌드

| 분류 | 색 | 정체성 | 비고 |
| --- | --- | --- | --- |
| **주문서** | 금색 | 빌드가 갈라지는 축. 각 빌드의 연계 카드가 주문서를 조건으로 삼습니다 | 불꽃 작렬·메테오·마력 폭주·불장판 |
| 치명(열기·메테오) | 노랑 | 치명타 2연속 → 메테오 즉시 시전을 키움 | 기존 치명에서 폭주 관련 분리 |
| **폭주** (신규 분류) | 보라 | 마력 폭주 5초에 모든 걸 몰아침 | 업화 2단계에 처음 열리는 '클리어 후 새 빌드' |
| 속사 | 주황 | 시전 횟수로 승부 | |
| 정령 | 초록 | 정령 수와 협공 | |
| 화상 | 빨강 | 지속 피해와 처치 후 전이 | |
| 공용 | 회색 | 어느 빌드에나 붙는 범용·대가형 | |

- 엑셀 `build` 열에 `spell`·`combustion` 값을 추가합니다. 카드 선택 창·도감·결과창의 빌드 색 표시가 이 값을 씁니다.
- 주력 빌드(2.5)를 셀 때 주문서와 공용은 제외합니다.

### 2.2 기존 카드 처리 (나눌 것 · 합칠 것 · 바꿀 것)

| 카드 | 처리 | 내용 |
| --- | --- | --- |
| 주문서 4장 | **이동** | 치명·화상 → 주문서 |
| 무모한 일격 | **이동** | 치명 → 폭주(이미 '치명타 15% 이상 또는 마력 폭주 보유'에서만 나오는, 폭주와 맞물린 카드) |
| 진홍의 마력 폭주 | **이동** | 치명 → 폭주 전설 |
| 수치 카드 6장 (신속의 불꽃·타오르는 집중·작열하는 열기·정령의 분노·맹렬한 화상·마력 증폭) | **겹치기 5 → 3** | 카드당 수치를 약 1.4배로 올려 최대치 합계는 비슷하게(예: 시전속도 +20% ×5 → +28% ×3). 남는 6~12번의 선택이 연계 카드로 갑니다 |
| 화염 정령 소환 | 유지(×4) | 정령 수가 빌드의 핵심 자원이라 유지 |
| 정령의 분노 vs 정령 계약 | **역할 분리** | 둘 다 '소환수 피해 증가'라 겹칩니다. 분노 = 일반 수치(×3), 계약 = 대가형으로 유지하고 연계는 신규 카드가 맡습니다 |
| 자동 영창 | 유지 | 피해 없는 편의 전설. 보스 전설 보장을 끝내지 않는 현행 규칙 유지 |

합칠 카드는 사실상 없습니다. 문제는 카드가 많아서가 아니라, 같은 역할(수치 +N%)이 겹쳐 있다는 점이라 '겹치기 축소 + 연계 카드 추가'로 풉니다.

### 2.3 새 카드 (시안 10장)

연계 카드는 **다른 빌드나 주문서의 결과를 자기 빌드의 자원으로 바꾸는** 효과를 기본으로 합니다. 화살표는 '무엇이 무엇을 채우는지'입니다.

| ID(가) | 이름(가) | 분류·등급 | 효과(시안) | 연계 | 선행 조건 | 출시 |
| --- | --- | --- | --- | --- | --- | --- |
| `rapid_chain` | 연쇄 장전 | 속사·희귀 | 화염구를 3번 시전할 때마다 불꽃 작렬 충전 +1 | 속사 → 치명 | 불꽃 작렬 보유 | **전** |
| `rapid_ember_trail` | 잔불 꼬리 | 속사·일반 | 화염구 적중마다 2초 화상(주문력 8%) | 속사 → 화상 | 없음 | 후 |
| `sum_heat_link` | 정령의 열기 | 정령·희귀 | 정령의 치명타도 열기를 채움(정령 치명타 확률은 마법사의 절반) | 정령 → 메테오 | 정령 보유 + 메테오 보유 | **전** |
| `sum_meteor_call` | 운석 소환술 | 정령·희귀 | 메테오 착탄 시 이번 스테이지 동안 정령 1기 추가(최대 +2) | 메테오 → 정령 | 정령 보유 + 메테오 보유 | 후 |
| `burn_detonate` | 기폭 | 화상·희귀 | 메테오 적중 시 대상의 남은 화상 피해를 즉시 터뜨림(+30%) | 메테오 → 화상 | 메테오 보유 | **전** |
| `burn_weak_spot` | 약점 연소 | 화상·일반 | 화상 중인 적에게 치명타 확률 +12% | 화상 → 치명 | 없음 | **전** |
| `burn_linger` | 끈질긴 불길 | 화상·일반 | 화상·불장판 지속시간 +50% (×2) | 화상 | 없음 | 후 |
| `comb_cycle` | 폭주 순환 | 폭주·희귀 | 폭주 중 화염구 시전마다 마력 폭주 재사용 대기시간 -0.5초 | 속사 → 폭주 | 마력 폭주 보유 | **전** |
| `comb_afterglow` | 잔광 | 폭주·희귀 | 폭주가 끝날 때 폭주 중 입힌 피해의 15%를 한 번 더 입힘 | 폭주 | 마력 폭주 보유 | 후 |
| `crit_ember_heart` | 불씨 심장 | 치명·일반 | 열기 2칸이 찰 때 다음 화염구 피해 +40% (메테오 없이도 열기가 쓸모 있게) | 치명 | 없음 | **전** |

- 선행 조건 `has_fireblast`, `has_summon_and_meteor`를 `buildCardFromData`의 해석기에 추가합니다.
- 업화 단계를 무너뜨린 전례(화염 기관총)가 있으므로, 새 카드는 **한 장씩 넣고 업화 0·1·4·8단계를 시뮬레이션**한 뒤 다음 카드로 넘어갑니다.

### 2.5 추첨 규칙 개편 (`drawChoices`)

| 규칙 | 내용(시안) |
| --- | --- |
| 주력 빌드 | 주문서·공용을 뺀 빌드 중 가장 많이 가진 빌드. 2장 이상일 때 성립. 동률이면 최근에 고른 빌드 |
| 가중치 | 주력 빌드 카드 ×1.8, 두 번째 빌드 ×1.3, 나머지 ×1 (등급 가중치에 곱함) |
| 1장 보장 | 일반 웨이브 3장 선택지에서 주력 빌드 카드가 한 장도 없으면, 마지막 장을 주력 빌드 카드로 교체 |
| 보스 전설 보장 | 현행 유지. 해금된 주력 빌드 전설이 있으면 그 전설을 우선 |
| 나머지 2장 | 지금처럼 무작위. 빌드를 갈아탈 여지를 남깁니다 |

- 시뮬레이터(`scripts/simulate-balance.cjs`)는 게임 코드를 그대로 불러 쓰므로 추첨 규칙 변경이 자동으로 반영됩니다. 정책별(`--policy all`) 클리어율·런 시간을 개편 전후로 비교합니다.
- 리스크: 가중치가 강하면 매 런이 같은 빌드로 굳습니다. 정책 `random`의 런별 주력 빌드 분포가 한쪽으로 몰리지 않는지 함께 봅니다.

## 3. 도감

### 3.1 진입 경로

| 어디서 | 여는 방법 | 열려 있는 동안 |
| --- | --- | --- |
| 타이틀 화면 | [📖 도감] | - |
| Esc 일시정지 메뉴 | [📖 도감] | 전투·스피드런 시계 정지 유지 |
| **각성 카드 선택 창** | 오른쪽 위 📖 버튼 | 선택 창 위에 겹쳐 열림. 닫으면 선택 창으로 돌아감(이미 일시정지 상태) |
| 결과창의 새 런 설정 | 시작 주문서 옆 📖 | 다음 런 계획용 |

- 각성 카드 선택 창이 가장 중요한 진입점입니다. 계획은 카드를 고르는 그 순간에 필요합니다.
- 도감 버튼은 **첫 각성 카드 선택 이후** 나타납니다(첫 실행 화면을 비워 둠).

### 3.2 화면

- 상단: 분류 탭 7개(2.1의 색). 탭에는 글자 대신 빌드 아이콘 + 색.
- 본문: 카드 격자. 카드 한 장 = 아이콘 + 이름 + 등급 테두리. 마우스를 올리면 설명(기존 카드 툴팁 재사용).
- 카드 상태 4가지:

| 상태 | 표시 |
| --- | --- |
| 미발견(선택지에 나온 적 없음) | 종이 실루엣 + ? |
| 발견 | 정상 표시 |
| 획득한 적 있음 | 오른쪽 아래 작은 불꽃 도장 |
| 잠김 | 실루엣 + 🔒 해금 조건(예: "숙련도 45", "업화 2단계") |

- **런 중 표시:** 지금 보유한 카드는 금색 테두리 + 겹친 횟수. 보유 카드와 연계되는 카드는 은은한 펄스 발광.
- **연계 선:** 카드를 하나 누르면 연계되는 카드들로 종이 실선이 이어집니다(2.3의 '연계' 열 데이터).

### 3.3 데이터

- 엑셀에 `links` 열(연계되는 카드 ID 목록)을 추가 → `roguelike-cards.json`. 도감 연계 선과 각성 카드 선택 창의 연계 발광이 같은 데이터를 씁니다.
- 영구 진행 `meta`에 `seenCards`(선택지에 나온 카드), `pickedCards`(획득한 카드)를 추가합니다. `normalizeMeta`가 구형 세이브를 빈 목록으로 받습니다.
- 새 문구는 `tr()` + `i18n-en.js`, 카드 이름·설명은 엑셀 영문 열.

### 3.4 각성 카드 선택 창의 연계 표시 (도감과 함께 구현)

- 선택지 카드가 보유 카드와 연계되면, 카드 위쪽에 보유 카드의 작은 아이콘이 종이 끈으로 매달려 나타납니다(쫀득한 오버슈트 팝업).
- 주력 빌드 카드에는 빌드 색 띠를 두릅니다. 글로 "추천"이라고 쓰지 않습니다.

## 4. 메뉴 구조

### 4.1 전체 흐름

```
[게임 실행]
   │
   ▼
타이틀 ──[시작 / 이어하기]──▶ 전투 ◀──[계속]── Esc 일시정지
   │  ├─[새 런]──▶ 새 런 설정(업화·시작 주문서) ──▶ 전투     ├─[도감]
   │  ├─[도감]                                              ├─[설정]
   │  ├─[명예의 전당]                                        ├─[런 포기]
   │  ├─[설정]                                              ├─[타이틀로]
   │  └─[종료]                                              └─[게임 종료]
   │
   └─ 전투 → 스테이지 클리어 → 각성 카드 선택(📖 도감) → 다음 스테이지
           → 최종 보스 토벌 / 패배 → 결과창 → [새 런] / [타이틀로]
```

### 4.2 타이틀 화면

- 배경: 현재 지역의 페이퍼 전장 아트 + 마법사 대기 호흡 모션, 불씨 파티클 소량. 가운데 로고(스토어 캡슐 로고 재사용).
- 버튼은 **해금될 때 나타납니다**(프로젝트의 Unfold 원칙).

| 버튼 | 나타나는 조건 | 동작 |
| --- | --- | --- |
| [시작] | 첫 실행(세이브 없음) | 큰 버튼 하나. 누르면 바로 1스테이지 |
| [이어하기] | 진행 중인 런이 있음 | 스테이지·경과 시간을 작은 글씨로 표시 |
| [새 런] | 첫 런을 한 번이라도 마침 | 진행 중 런이 있으면 "런을 포기합니다" 확인. 업화·시작 주문서가 해금됐으면 새 런 설정으로 |
| [📖 도감] | 첫 각성 카드 선택 이후 | 3장 |
| [🏆 명예의 전당] | 첫 최종 보스 토벌 | 기존 명예의 전당 창 |
| [⚙ 설정] | 항상(작은 아이콘) | 4.4 |
| [종료] | 데스크톱 빌드만(작은 아이콘) | 마지막 저장 후 종료 |

- 첫 실행에서 전투까지 걸리는 클릭은 1번입니다. 지금의 "켜자마자 손맛" 장점을 유지합니다.
- 진입·이탈 연출: 버튼은 부드러운 감속 안착으로 차례로 펼쳐지고, [시작]을 누르면 로고가 위로 빠지며 전장이 확대되는 0.8초 전환.

### 4.3 Esc 일시정지 메뉴

- **여는 방법:** Esc, 화면 오른쪽 위 ⏸ 버튼(마우스용), **창이 포커스를 잃거나 최소화될 때 자동**(Electron `blur`·`minimize`, 웹 `visibilitychange`).
- **멈추는 것:** 전투, 주문 재사용 대기시간, 시전, 스피드런 시계 전부(`state.isPaused`). 스피드런 기록은 게임 내 시간 기준이므로 일시정지가 기록에 영향을 주지 않습니다.
- **메뉴:** [계속] · [📖 도감] · [⚙ 설정] · [런 포기] · [타이틀로] · [게임 종료](데스크톱만)
  - [런 포기]: 확인 후 패배 결과창으로(실패 보상·숙련도 경험치는 현행 패배 규칙대로).
  - [타이틀로]: 런은 저장된 채 유지 → 타이틀의 [이어하기].
- **복귀 호흡:** [계속]을 누르면 0.6초 동안 화면이 다시 밝아진 뒤 전투가 재개됩니다(이 동안도 시계 정지). 손을 다시 올릴 시간입니다.
- **다른 모달과의 관계:** 각성 카드·결과창이 떠 있을 때 Esc는 그 창 위에 일시정지 메뉴를 겹칩니다. 메테오 연계 안내(코치) 말풍선이 Esc를 닫기 키로 쓰고 있으므로(`game.js` 키 처리), 말풍선이 떠 있으면 Esc는 말풍선만 닫습니다.

### 4.4 설정 화면

| 묶음 | 항목 | 비고 |
| --- | --- | --- |
| 게임 | 언어(한국어 / English) | 상단 🌐 버튼에서 이동(✅). 바꾸면 저장 후 새로고침 |
| 게임 | 모션 감소(시스템 설정 따름 / 켬 / 끔) | 지금은 OS 설정(`prefers-reduced-motion`)만 따름 → 게임 안 선택을 우선하도록 |
| 사운드 | 전체 · 배경음 · 효과음 볼륨, 음소거 | 상단 🔊 팝오버에서 이동 |
| 화면 | 전체화면 / 창 | 데스크톱만. F11·Alt+Enter와 같은 동작 |
| 화면 | 창 크기 1280×800 · 1600×900 · 1920×1080 | 데스크톱 창 모드만 |
| 데이터 | 진행 초기화 | 상단 🗑️에서 이동. 2단계 확인("초기화" 입력 또는 길게 누르기) |

- 설정 값은 지금처럼 세이브에 저장합니다(`soundOn`·볼륨은 이미 저장 중). 창 크기·전체화면은 Electron 쪽에 저장합니다.

### 4.5 전투 화면 상단 정리

| 지금 | 개편 후 |
| --- | --- |
| 🌐 언어 · 🏆 명예의 전당 · 🔊 사운드 · 🗑️ 초기화 | ⏸ 하나(일시정지 메뉴) |

전투 화면에는 스테이지·시간·골드·능력치 같은 전투 정보만 남깁니다.

### 4.6 만들지 않는 것

- **저장 슬롯:** 15분 런 로그라이트는 자동 저장 1개 + 이어하기로 충분합니다. 슬롯 선택은 첫 실행 → 전투까지의 단계만 늘립니다. 세이브는 지금처럼 하나(`MAGE_SLAYER_STAGE_SAVE_V7`)이고, Steam 자동 클라우드로 동기화합니다.
- **별도 "새 게임" 확인 단계:** [새 런]이 그 역할을 합니다.

## 7. 남은 질문

- 정령의 치명타가 열기를 채우게 하면(정령의 열기) 정령 수가 많은 빌드에서 메테오가 과하게 자주 떨어질 수 있습니다. 정령 치명타 확률을 마법사의 절반으로 둔 것은 그 상한 장치이며, 시뮬레이션으로 확인합니다.
- 도감에서 미발견 카드를 실루엣으로 숨길지, 처음부터 모두 보여 줄지. 이 문서는 '숨김'을 제안합니다(발견의 재미). 숨겨도 해금 조건은 보이게 해서 계획에는 지장이 없게 합니다.
- 일시정지 중 화면을 흐리게 할지(전투 내용 가림). 스피드런에서 일시정지로 상황을 분석하는 악용을 막으려면 흐리게 하는 편이 낫습니다.
