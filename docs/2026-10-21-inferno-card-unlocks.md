# 업화 해금 카드: 마력 폭주(2단계)·화염 기관총(3단계), 숙련도 10 = 들불 (2026-10-21)

## 변경
| 항목 | 이전 | 이후 |
| --- | --- | --- |
| 주문서: 마력 폭주(희귀) | 기본 카드 풀(첫 런부터 등장) | 업화 2단계에 처음 도달하면 영구 해금 |
| 화염 기관총(전설) | 숙련도 10 | 업화 3단계에 처음 도달하면 영구 해금 |
| 들불(전설) | 숙련도 100 | 숙련도 10(화염 기관총이 빠진 자리. 가장 약한 전설) |
| 시작 주문서: 마력 폭주 | 숙련도 320 | 숙련도 320 + 업화 2단계 |

- 표: `meta-progression.js` `INFERNO_CARD_UNLOCKS`, 잠금 계산: `getLockedCardIds(xp, infernoUnlocked)`.
- 결과창: 업화 단계 도달 연출 뒤에 열린 카드를 한 칸 더 공개합니다. 새 런 설정에 '🔒 업화 N단계 도달 시 해금' 예고가 붙고, 해금 칸에 마우스를 올리면 카드 설명이 뜹니다.

## 시뮬레이션 (greedy, 20회씩 같은 시드. 수정 전은 직전 커밋 `ea9afd8^` 작업 폴더에서 측정)
| 조건 | 수정 전 클리어 · 중앙 | 수정 후 클리어 · 중앙 |
| --- | --- | --- |
| 첫 런(`--locked`, 숙련도 0) | 19/20 · 14:16 | 18/20 · 14:18 |
| 세 번째 런(`--xp 15 --start fireblast`) | 20/20 · 5:14 | 20/20 · 10:44 |
| 업화 0단계(숙련도 전부, 업화 미도달) | 20/20 · 5:45 | 20/20 · 12:03 |
| 업화 1단계 | 20/20 · 8:51 | 16/20 · 15:55 |
| 업화 2단계(마력 폭주 열림) | 20/20 · 8:51 | 19/20 · 8:27 |
| 업화 3단계(둘 다 열림) | 20/20 · 8:51 | 20/20 · 8:51 |

- 두 카드가 난이도를 무너뜨렸다는 판단이 수치로 맞았습니다. 숙련도를 다 연 0단계 런은 두 카드가 빠지자 런 시간이 두 배 넘게 늘었습니다.
- 세 번째 런은 화염 기관총 때문에 5분대로 끝나 학습 구간이 사라졌습니다. 들불로 바꾸자 10분대로 돌아왔습니다.
- 20회 측정에서는 업화 1단계(16/20)가 2·3단계보다 어려워 보였습니다. 아래 40회 재측정에서 이는 표본 오차로 확인됐습니다.

## 업화 1단계 재측정 (2026-10-22, greedy, `--runs 40 --seed 101`)
| 조건 | 클리어 | 런 시간 p25 / 중앙 / p75 | 실패 스테이지 |
| --- | --- | --- | --- |
| 업화 0단계 | 40/40 | 9:19 / 12:24 / 15:23 | - |
| 업화 1단계 (체력 +15%, 현행) | 37/40 | 11:15 / 13:11 / 14:44 | 5, 5, 10 |
| 업화 1단계 (체력 +8% 시험) | 40/40 | 10:35 / 13:17 / 15:47 | - |
| 업화 1단계 (체력 +5% 시험) | 39/40 | 10:01 / 12:29 / 14:36 | 5 |
| 업화 2단계 (마력 폭주 열림) | 33/40 | 8:06 / 10:21 / 12:20 | 5, 5, 5, 10, 15, 20, 20 |

- **결정: 1단계 규칙(몬스터 체력 +15%)을 그대로 둡니다.** 클리어율이 0단계 100% → 1단계 92.5% → 2단계 82.5%로 단계마다 내려가 난이도 곡선이 바르게 이어집니다. +8%로 낮추면 1단계가 0단계와 같은 100%가 되어 첫 단계의 의미가 사라집니다.
- 2단계는 런 시간이 더 짧지만 실패도 더 많습니다. 마력 폭주가 '빠르지만 위험한' 빌드를 열어 주는 것이라, 해금 보상으로서 의도에 맞습니다.
- 확인할 점: 2단계 실패 7회 중 3회가 5스테이지 보스입니다. 2단계 규칙(보스 광폭화 -30%)은 10스테이지부터 적용되므로, 원인은 규칙이 아니라 마력 폭주를 일찍 고른 빌드로 보입니다. 실제 플레이 로그로 같은 현상이 보이면 첫 보스 전 마력 폭주의 출현 시점을 검토합니다.
