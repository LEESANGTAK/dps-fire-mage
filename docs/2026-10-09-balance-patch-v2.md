| 항목 | 결정 |
| --- | --- |
| 목표 런 시간 | 첫 클리어 기준 15분 내외 |

## 전투·성장 규칙 변경

- **스탯 단위 통일:** 카드 스탯은 모두 정수 퍼센트입니다.
  - 주문력은 기본 100에 `spPct`가 곱해집니다(고정 +15 주문력 같은 카드는 폐지).
  - 새 스탯 `burnPct`(지속 피해)와 `spiritPct`(소환수 피해)를 추가했습니다.
  - 대가형 카드는 음수 값으로 손해를 표현합니다. 주문력·가속에는 하한이 있습니다.
- **충전형 카드:** 스테이지 시작마다 충전이 다시 채워집니다. 남은 충전은 해당 스킬 버튼 좌하단 배지로 표시됩니다(🎇 화염구, 🔋 메테오).
- **보스 광폭화:** HP 바 아래 게이지로 남은 시간을 보여주고, 10초 이하에서는 붉게 점멸합니다.
  - 시간이 0이 되면 1.2초 여운 뒤 실패 결과창이 뜹니다.
  - 실패 상태는 저장되므로 새로고침으로 재시도할 수 없습니다.
- **리롤 비용:** 현재 스테이지 처치 골드 × (1 + 이번 선택에서 리롤한 횟수).
- **스킬 조정:**
  - 불꽃 작렬: 피해 85% → 120%, 충전 9초 → 8초
  - 마력 폭주: 지속 2초 → 5초
  - 불장판: 틱 피해 40% → 50%
- **화상(ignite) 버그 수정:**
  - 기존에는 정령 공격이 화상 시간을 최대 6초까지 늘려 화상 풀이 치명타마다 기하급수로 불어났습니다(정령 빌드 20스테이지 DPS가 최대 774만).
  - 이제 화상은 "치명타 피해 × 22%"짜리 피해 풀을 틱마다 나눠 소모하는 정상 모델입니다.
  - 회귀 테스트: `tests/ignite-balance.test.cjs`
- **불사조:** 불사조의 가호 카드가 공격만 하고 몸체가 보이지 않던 문제를 수정했습니다(마법사 어깨 위에 표시).

## 스테이지 HP · 광폭화

HP는 실측형 시뮬레이터로 보정했습니다.

- greedy 전략 30런에서 스테이지별 실제 DPS 중앙값을 측정하고, 이웃 스테이지와 기하 평균으로 평활화했습니다.
- 그 값에 목표 처치 시간을 곱해 HP를 정했습니다.
- 광폭화 시간은 후반으로 갈수록 편차가 커지는 점을 반영해 여유를 넓혔습니다.

| 보스 | 목표 처치 | HP | 광폭화 |
| --- | --- | --- | --- |
| 5 붉은송곳니 군주 | 45초 | 8,200 | 110초 |
| 10 동굴 오우거 대족장 | 65초 | 28,500 | 160초 |
| 15 붉은 화염 비룡 | 75초 | 75,000 | 210초 |
| 20 화염군주 라그나로스 | 90초 | 225,000 | 270초 |

## 수치 조정 방법

```bash
# 전략별 클리어율·런 시간·피해 점유율 (기본 20런)
npm run simulate

# 목표 처치 시간 기준 스테이지 HP 제안
npm run simulate -- --calibrate --runs 30
```

- **카드 수치:** `src/data/roguelike-cards.json`(또는 엑셀)을 수정한 뒤 `npm run sync-card-fallback`으로 내장 fallback 카드를 맞춥니다. 엑셀 동기화(`npm run sync-cards`)는 이 작업을 자동으로 합니다.
- **HP·광폭화:** `src/scripts/game.js`의 `STAGE_MONSTERS`
- **목표 처치 시간:** `scripts/simulate-balance.cjs`의 `TARGET_TTK`
- **엑셀 주의:** 엑셀은 새 열 구성(주문력%·지속피해%·소환수% 등)을 씁니다. 구형 엑셀로 동기화하면 데이터를 덮어쓰지 않고 중단하니, 먼저 `npm run export-cards`로 다시 생성하세요(Python `openpyxl` 필요).
